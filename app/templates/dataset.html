📚 Feature Dictionary & Data Schema Column Metadata

Detailed breakdown of feature descriptions and roles within the Avazu CTR predictive dataset:

🎯 Target & Identifiers

  • click Target binary label (1 = Ad Clicked, 0 = No Click).
  • id Unique 64-bit integer impression ID (dropped during modeling).
  • hour Impression timestamp format (YYMMDDHH).

🌐 Publisher & App Context

  • banner_pos Slot position of the ad banner on screen (0, 1, 2).
  • site_id / domain / category Anonymized web publisher metadata.
  • app_id / domain / category Mobile application publisher attributes.

📱 User Device Signals

  • device_id / device_ip Anonymized user device & IP identifiers.
  • device_model Hardware device model code.
  • device_type Device category (Phone, Tablet, Desktop, TV).
  • device_conn_type Connection protocol (Wifi, 3G, 4G, 5G).

⚙️ Anonymized Avazu Features

  • C1 Categorical feature identifier 1.
  • C14 - C21 Encrypted numerical & categorical ad auction interaction features.
