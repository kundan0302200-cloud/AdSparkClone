🛠️ Step-by-Step Transformation Pipeline Sequential Steps

1

Identifier Filtering

Drops non-predictive impression identifiers (id) to prevent model memorization and overfitting.

2

Missing Value Imputation

Uses SimpleImputer(strategy='median') fitted strictly on training numerical features to fill missing entries without data leakage.

3

Numerical Standardization

Applies StandardScaler ($\mu=0, \sigma=1$) to numerical values ensuring equal gradient step weighting for linear and gradient boosting models.

4

One-Hot Categorical Encoding

Encodes categorical variables with $\le 50$ unique levels using OneHotEncoder(handle_unknown='ignore', sparse_output=False).

5

Ordinal Categorical Encoding

Encodes high-cardinality categorical features using OrdinalEncoder(unknown_value=-1) to preserve feature dimensions.
